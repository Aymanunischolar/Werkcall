# NordWerk Haustechnik GmbH — Frequently Asked Questions (English)

Only this file is an approved knowledge source for `search_faq`. If an answer
is not contained here, the assistant must return `NOT_FOUND` and must never

## What services does NordWerk Haustechnik offer?
We offer heating repair, maintenance, new installation, and appointment
changes for heating systems across our service area.

## How quickly can a technician come for a heating failure?
For a reported heating failure we typically offer an appointment within 24
to 48 hours, depending on calendar availability.

## What should I do if I smell gas?
This is an emergency. Leave the building immediately, open windows and
doors, and call your local emergency number. Contact us only afterward.

## How do I change or cancel an existing appointment?
Call us and give your booking number. The assistant will read back the new
or cancelled appointment for confirmation before anything is saved.

## Which postal code areas do you serve?
We currently serve selected postal code areas in northern Germany. The
assistant checks this live through calendar availability.
